# Identidade visual — "Laboratório digital"

Retrô + tecnologia + organização. O Pac-Man é assinatura, não decoração: aparece no logotipo, numa faixa animada no hero e em detalhes discretos.

## Cores com função
| Cor | Token | Função |
|---|---|---|
| 🟡 Amarelo `#F5C518` | `--pac` | destaque principal, ações, foco |
| 🔵 Azul labirinto `#2F6BFF` | `--maze` | tecnologia, bordas, estrutura |
| 🟢 Verde `#22C55E` | `--ok` | concluído |
| 🔴 Vermelho `#EF4444` | `--danger` | atenção / bloqueado |
| 🟣 Rosa/roxo `#E879F9` | `--special` | portfólio / projetos especiais |
| 🟠 Laranja `#FB923C` | `--test` | em teste |
| ⚪ Branco/cinza | `--text` / `--muted` | texto e documentação |

Fundo: preto azulado `#07090F` com superfícies `#0E1422`. Tema claro disponível.

## Tipografia
- **Press Start 2P** — somente logotipo e rótulos curtos (pixel art controlada).
- **Inter** — todo o texto de leitura.
- **JetBrains Mono** — números, versões, código.

## Regras
- Neon só em foco/hover e no logotipo; nunca em blocos de texto.
- Toda animação tem alternativa estática e respeita `prefers-reduced-motion`.
- O layout precisa ser profissional mesmo com animações desligadas.
