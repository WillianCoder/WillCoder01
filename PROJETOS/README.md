# 💻 Projetos

Projetos de desenvolvimento e projetos pessoais. Um projeto por pasta (`PROJETOS/nome-do-projeto/`), com a estrutura de [`TEMPLATES/projeto`](../TEMPLATES/projeto/).

**Categorias** (campo `categoria` do `meta.json`): Desenvolvimento · Pessoal · Automação · Inteligência Artificial · APIs · Banco de Dados · Web.
Tecnologias (C#, .NET, Python, JavaScript…) ficam no campo `tecnologias` — assim um projeto aparece em várias buscas sem ser duplicado em várias pastas.

> Índice gerado automaticamente no painel ([index.html](../index.html)). Para criar um item aqui, veja [Como adicionar conteúdo](../DOCUMENTACAO/como-adicionar-conteudo.md).
