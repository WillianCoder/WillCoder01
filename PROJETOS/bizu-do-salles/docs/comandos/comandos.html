Bizu do Salles: guia rápido de comandos

Um mapa para você abrir, conferir, adicionar e remover cada parte do projeto no VS Code (Windows). Guarde este PDF junto do docs/RELATORIO.pdf, que explica o projeto em detalhe.

Regra de ouro: antes de mexer, rode git pull. Depois de mexer, rode npm test. Se passar, está seguro.

1. Abrir o projeto e o terminal

  1. No VS Code: Arquivo → Abrir Pasta… e escolha WillCoder01\PROJETOS\bizu-do-salles.
  2. Abra o terminal: menu Terminal → Novo Terminal (ou Ctrl + ').
  3. Se o PowerShell bloquear scripts, clique na setinha ao lado do + do terminal e escolha Command Prompt.
Atalho do VS CodePara quê
Ctrl + PAchar um arquivo pelo nome (digite, por exemplo, site.ts).
Ctrl + Shift + FProcurar um texto em todo o projeto (por exemplo, uma frase da página inicial).
Ctrl + FProcurar dentro do arquivo aberto.
Ctrl + SSalvar.
Ctrl + ZDesfazer.
Ctrl + C (no terminal)Parar o site que está rodando.

4. Adicionar e remover: passo a passo

4.1 Questões

Uma questão (mais fácil): entre no site como admin, vá em Admin → Questões → Nova questão, preencha e salve.

Várias questões (arquivo):

  1. Em content/questoes/, copie um arquivo parecido e renomeie (por exemplo, sp-cesp-01-seguranca.json).
  2. Troque o conteúdo mantendo o formato abaixo. O code de cada questão precisa ser único.
  3. Rode npm test e depois npm run db:seed.
{
  "cycle": "SPECIFIC",           ← "BASIC" ou "SPECIFIC"
  "subject": "Disciplina",
  "topic": "Assunto",
  "state": "SP",                 ← apague esta linha para valer no Brasil todo
  "sourceLicense": "Questões originais Bizu do Salles.",
  "author": "Bizu do Salles",
  "questions": [
    {
      "code": "CESP-SEG-001",
      "difficulty": "EASY",      ← EASY, MEDIUM ou HARD
      "statement": "Enunciado…",
      "options": { "A": "…", "B": "…", "C": "…", "D": "…", "E": "…" },
      "correct": "C",
      "explanation": "Por que a C está certa (mínimo 20 letras).",
      "reference": "Art. 5º, inciso X"
    }
  ]
}

Também dá para importar CSV: Admin → Importar.

Remover uma questão: em Admin → Questões, abra a questão e mude o status para Arquivada. Assim ela some para os alunos, mas o histórico deles continua certo.

Apagar do JSON não tira a questão do banco: o seed só adiciona. Remova sempre pelo painel.

4.2 Materiais e resumos

Pelo painel: Admin → Materiais, para criar, editar ou despublicar.

Por arquivo: copie um arquivo de content/materiais/, troque title e body (aceita ## títulos, **negrito** e listas com -) e rode npm run db:seed. Com "free": true, o material fica liberado para todos.

4.3 Planos, preços e cupons

Tudo pelo painel: Admin → Planos e preços e Admin → Cupons. Não precisa mexer em código.

4.4 Usuários e acesso

Admin → Usuários: liberar ou estender um plano, bloquear, trocar o papel (ADMIN/EDITOR). Para criar um admin, use npm run admin:create.

4.5 Textos, cartões e perguntas frequentes

Abra src/config/site.ts.

  • Adicionar um cartão: copie uma linha { icone: …, titulo: …, texto: … }, e cole logo abaixo.
  • Adicionar uma pergunta frequente: copie uma linha ["pergunta", "resposta"],.
  • Remover: apague a linha inteira, incluindo a vírgula do fim.

4.6 Item do menu do aluno

Em src/app/app/layout.tsx, na lista NAV: cada linha é um item. Cuidado: a lista MOBILE, logo abaixo, usa as posições da NAV (NAV[0], NAV[9]…); se apagar uma linha, confira essas posições. Para acrescentar, a página precisa existir em src/app/app/NOME/page.tsx. Peça ajuda nesse caso.

4.7 Regras e números

Em src/config/regras.ts, troque só os números. Exemplos: diasValidade: 30 define quantos dias o aluno fica logado; gratisPorArquivo: 3 define quantas questões grátis cada arquivo novo libera.

6. Erros comuns

MensagemSolução
"execução de scripts foi desabilitada"Use o Command Prompt ou rode Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
EPERM ou ENOTEMPTY no npm installFeche o VS Code e o site, rode rmdir /s /q node_modules e depois npm install
"@prisma/client did not initialize yet"npx prisma generate
"Port 3000 is in use"Já existe um site rodando: feche o outro terminal ou use Ctrl + C
Erro no npm test apontando um JSONVírgula faltando ou sobrando, ou code repetido. O erro mostra o arquivo e a linha.
Página em brancoPare com Ctrl + C, rode git pull e npm install, depois npm run dev de novo.
Resumo: textos em src/config/site.ts · regras em src/config/regras.ts · cores em globals.css · questões e materiais em content/ ou no painel · preços, cupons e usuários no painel · depois de editar, sempre npm test.
