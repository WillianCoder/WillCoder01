# 🌳 Boneco IA

> ![Status](https://img.shields.io/badge/status-em%20desenvolvimento-f5c518) ![Versão](https://img.shields.io/badge/vers%C3%A3o-0.3.1-f5c518)

Boneco impresso em 3D com IA **100 % offline e gratuita**: acorda pelo nome e responde com a voz do personagem (árvore, dragão, robô ou coruja). Funciona no Raspberry Pi e no Windows.

## 📦 Repositório próprio
O código, os guias e os PDFs ficam em **[github.com/WillianCoder/boneco-ia](https://github.com/WillianCoder/boneco-ia)**.

Esta pasta só registra o projeto no painel do Laboratório Digital.
