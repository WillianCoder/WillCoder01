# Fotos dos banners

Fotos horizontais (~1600×700 px, até ~250 KB) para o carrossel da página inicial. Use no campo `imagem` de `banners` em `js/config.js`:

```js
imagem: "img/banners/coturnos.jpg",
```

Guia completo: [docs/GUIA-DE-EDICAO.md](../../../docs/GUIA-DE-EDICAO.md#4-banners-da-página-inicial)
