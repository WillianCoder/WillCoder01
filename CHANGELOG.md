## [1.0.0] - 2026-09-29
### Adicionado
- Estrutura de pastas: `PROJETOS`, `ACADEMICO`, `ESTUDOS`, `EXPERIMENTOS`, `PORTFOLIO`, `DOCUMENTACAO`, `RECURSOS`, `ARQUIVO`, `TEMPLATES`.
- Painel web (`index.html`) com identidade Pac-Man: hero animado em CSS puro, dashboard automático, portfólio, busca e filtros, estudos com progresso, acadêmico por semestre, página Sobre, tema claro/escuro, pausa de animações.
- `scripts/catalogo.py`: gera catálogo e estatísticas, valida `meta.json` e links internos.
- `scripts/novo.py`: cria projetos, trabalhos, estudos e experimentos a partir dos templates.
- Templates, documentação, `perfil.json`, licença MIT, `SECURITY.md`, `CONTRIBUTING.md`, `.gitignore`, `.editorconfig`.
- GitHub: CI de validação, deploy no GitHub Pages, templates de issue e pull request.
- Registro do primeiro exercício (2024) em `EXPERIMENTOS/2024/primeira-pagina-web/`.

### Preservado
- Arquivos do primeiro commit (`gato.html`, `style.css`, `script.js`, `desktop.ini`) mantidos na raiz, sem alterações.
