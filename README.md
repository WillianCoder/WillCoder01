## ⚡ Início rápido
```bash
# abrir o painel: dois cliques em index.html (não precisa de servidor)

python scripts/novo.py projeto "Nome do Projeto"   # criar item a partir do template
python scripts/catalogo.py                         # validar e atualizar painel + README
```
Guia completo: [Como adicionar conteúdo](DOCUMENTACAO/como-adicionar-conteudo.md).
