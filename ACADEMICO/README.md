# 🎓 Acadêmico

Trabalhos, seminários, projetos, exercícios, pesquisas, artigos, resumos e apresentações da faculdade.

**Organização:** `ACADEMICO/<ano>-<semestre>/<disciplina>/<trabalho>/` — por exemplo `ACADEMICO/2026-2/redes-de-computadores/seminario-tcp-ip/`. Assim, trabalhos antigos são encontrados pelo semestre ou pela busca do painel.

A versão entregue fica sempre em `versao-final/`.
